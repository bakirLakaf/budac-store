# نشر المتجر على Railway — بلا Python ولا Git

هاد الدليل مكتوب لجهاز عادي: **ما تحتاج تثبّت والو**. كلشي عبر المتصفح.

الوقت التقريبي: **20-30 دقيقة**.

## المرحلة 1: ارفع الكود لـGitHub

GitHub هو المكان اللي يخزّن الكود، وRailway ياخذو منو.

### 1.1 أنشئ حساب

روح لـ[github.com](https://github.com) واعمل حساب (مجاني).

### 1.2 أنشئ مستودع (Repository)

- دوس على **+** فوق على اليمين ← **New repository**
- الاسم: `budac-store`
- اختر **Private** ⚠️ (مهم — الكود فيه منطق متجرك)
- **لا تعلّم** على "Add a README file"
- دوس **Create repository**

### 1.3 ارفع الملفات

فالصفحة اللي تبان، دوس على **uploading an existing file**.

دابا:
1. فك ضغط ملف `budac-store-v13.zip` على جهازك
2. افتح المجلد `budac-store` — لازم تشوف فيه `app.py` و`models.py`...
3. **حدد كل الملفات والمجلدات اللي داخلو** (Ctrl+A)
4. اسحبهم لصفحة GitHub

⚠️ **مهم**: اسحب **محتوى** المجلد، ماشي المجلد نفسو. لازم `app.py` يكون فالجذر.

5. تحت، اكتب `first upload` ودوس **Commit changes**

انتظر شوية حتى ترفع كل الملفات (~100 ملف).

## المرحلة 2: أنشئ المشروع على Railway

### 2.1 الحساب

روح لـ[railway.com](https://railway.com) ← **Login with GitHub**.

⚠️ Railway يعطي رصيد تجريبي صغير. باش الموقع يبقى شغال دائمًا، خاصك تفعّل
**Hobby plan** ($5/شهر) من **Settings ← Plans**.

### 2.2 اربط الكود

- **New Project** ← **Deploy from GitHub repo**
- إذا طلب صلاحيات، وافق (**Configure GitHub App** ← اختر `budac-store`)
- اختر `budac-store`

Railway يبدا ينشر تلقائيًا. **غادي يفشل أول مرة** — هذا عادي، لأن قاعدة
البيانات والإعدادات مازال ما زدناهمش.

### 2.3 زيد قاعدة البيانات

- فنفس المشروع: **+ New** ← **Database** ← **Add PostgreSQL**

Railway يربطها تلقائيًا ويعطي `DATABASE_URL` للتطبيق.

### 2.4 زيد قرص التخزين (للصور)

⚠️ **هاد الخطوة ضرورية.** بلاها، أي صورة يرفعها الأدمن **تنمسح** عند أول
تحديث للموقع — لأن نظام ملفات Railway مؤقت.

- دوس على خدمة التطبيق (ماشي قاعدة البيانات)
- تبويب **Settings** ← نزل لـ**Volumes** ← **Add Volume**
- **Mount path**: اكتب `/data`
- احفظ

## المرحلة 3: الإعدادات (متغيرات البيئة)

دوس على خدمة التطبيق ← تبويب **Variables** ← **New Variable**.

زيد **واحد بواحد**:

| الاسم | القيمة |
|---|---|
| `SECRET_KEY` | المفتاح الطويل اللي ولّدتو |
| `UPLOAD_ROOT` | `/data` |
| `SESSION_COOKIE_SECURE` | `true` |
| `ADMIN_USERNAME` | اسم المستخدم اللي تختارو |
| `ADMIN_PASSWORD` | كلمة سر قوية (**8 حروف على الأقل**) |
| `STORE_NAME` | `BUDAC` |
| `STORE_TAGLINE` | `ديكور و إكسسوارات` |
| `WHATSAPP_NUMBER` | `213676672334` |

**اختيارية** (زيدها إذا عندك):

| الاسم | القيمة |
|---|---|
| `ZR_TENANT_ID` | من ZR Express |
| `ZR_API_KEY` | من ZR Express |
| `FACEBOOK_PIXEL_ID` | من مدير إعلانات فيسبوك |
| `TIKTOK_PIXEL_ID` | من TikTok Ads |
| `YOUCAN_ACCESS_TOKEN` | من YouCan |

بعد ما تزيدهم كلهم، Railway يعاود ينشر لوحدو.

## المرحلة 4: افتح الموقع

- تبويب **Settings** ← قسم **Networking** ← **Generate Domain**
- يعطيك رابط كيما `budac-store-production.up.railway.app`

افتحو. لازم تشوف المتجر.

**لوحة التحكم**: `الرابط/admin/login` — بالاسم وكلمة السر اللي حطيتهم فالإعدادات.

## المرحلة 5: زيد منتجاتك

الموقع نشر **بلا منتجات**. عندك خيارين:

### أ) استورد من YouCan (أسرع)

هاد يحتاج تشغيل سكريبت، وأنت ما عندكش Python. الحل: **Railway Shell**.

- خدمة التطبيق ← الثلاث نقاط (⋮) ← **Shell** (أو **Terminal**)
- اكتب: `python import_from_youcan.py`

⚠️ إذا ما لقيتش خيار Shell (يتغيّر حسب خطتك)، استعمل الخيار (ب).

### ب) يدويًا من لوحة التحكم

المنتجات ← **+ منتج جديد**. لـ26 منتج ياخذ وقت، لكن يخليك تراجع كل منتج.

## تحديث الموقع بعدين

كي نعطيك نسخة جديدة:

1. فـGitHub، افتح المستودع
2. **Add file** ← **Upload files**
3. اسحب الملفات المعدّلة (يبدّل القديم تلقائيًا)

## مشاكل شائعة

### الموقع يعطي "Application failed to respond"

شوف **Deployments ← View Logs**. الأسباب المعتادة:

| فالسجل | الحل |
|---|---|
| `no such table` | قاعدة البيانات ما تربطاتش — تأكد أن PostgreSQL مضافة |
| `SECRET_KEY` | ناقص من Variables |
| `ModuleNotFoundError` | ملف `requirements.txt` ما ارتفعش |

### الصور تختفي بعد التحديث

`UPLOAD_ROOT=/data` ناقص، أو الـVolume ما اتركّبش على `/data`. راجع 2.4 و3.

### "CSRF token expired" عند تسجيل الدخول

`SECRET_KEY` تبدّل بين النشرات. تأكد أنو **ثابت** فالـVariables.

### الدخول للوحة التحكم ما يخدمش

`SESSION_COOKIE_SECURE=true` يحتاج **https**. رابط Railway أصلاً https، فهذا مليح.
لكن إذا فتحت الموقع بـhttp، الجلسة ما تخدمش — استعمل https دائمًا.

## ⚠️ "Out of memory" أثناء الاستيراد

سببو معالجة الصور: الصورة الوحدة من الهاتف تاخذ عشرات الميغابايتات كي تتفك
فالذاكرة، ومعاها الموقع شغال.

**اتحل فالكود** — الصور ولّات تتفك مباشرة بحجم صغير (`draft`)، والذاكرة تتحرّر
بعد كل صورة. جرّبنا 10 صور 3024×4032: **صفر زيادة** فالذاكرة.

### إذا رجع الخطأ رغم هذا

استورد **على دفعات**:

```bash
python import_from_youcan.py --limit 5
```

عاود نفس الأمر عدة مرات — المنتجات الموجودة **يتخطاهم تلقائيًا**، فما فيه تكرار.

### أو: بلا صور أولاً

```bash
python import_from_youcan.py --skip-images
```

يجيب المنتجات والتنويعات والأسعار **بسرعة وبأقل ذاكرة**، وتزيد الصور بعدين
يدويًا من لوحة التحكم.

### تقليل استهلاك الموقع

Procfile مضبوط على **عامل واحد** (`--workers 1`) مع 4 خيوط — كافي لمتجر
فبدايتو. إذا كبر الترافيك وزدت الذاكرة، زيد متغير:

```
WEB_WORKERS=2
```
