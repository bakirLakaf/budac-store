# مكاتب World Express

هاد الملف (`data/world_offices.json`) فارغ حتى تعمّرو بالمكاتب الحقيقية.

## الشكل

```json
[
  {
    "name": "Hub Jijel مكتب جيجل 18",
    "wilaya_code": "18",
    "commune": "Jijel",
    "address": "شارع الاستقلال",
    "pickup": true
  }
]
```

## الحقول

| الحقل | إجباري | الشرح |
|---|---|---|
| `name` | ✅ | اسم المكتب كيما تبعثو للشركة — **هو المعرّف** |
| `wilaya_code` | ✅ | رمز الولاية بخانتين: `"18"` ماشي `18` ولا `"8"` |
| `commune` | ❌ | البلدية — تبان للزبون إذا `address` فارغ |
| `address` | ❌ | العنوان — يبان تحت اسم المكتب |
| `pickup` | ✅ | `true` = يستلم الزبائن · `false` = مركز فرز برك، ما يبانش |

## ⚠️ نقاط تخلّي الأمور تطيح

1. **`wilaya_code` لازم نص بخانتين** — `"01"` ماشي `1`. الكود يقرّبها
   بـ`zfill(2)` لكن الأحسن تكون صحيحة من البداية.
2. **`pickup: false`** = المكتب ما يبانش للزبون. إذا كل مكاتب ولاية
   `false`، الولاية تولّي بلا خيار مكتب.
3. **الاسم يتبعث كيما هو** لشركة التوصيل — اكتبو بالضبط كيما هو
   عندهم، بلا زيادة ولا نقصان.

## بعد التعديل

عاود شغّل الموقع (ولا انشر). الملف يتقرا مرة وحدة ويتخزّن فالذاكرة.

## باش تزيد شركة ثالثة

1. `data/<code>_offices.json`
2. زيد سطر فـ`OFFICE_FILES` فـ`services/carrier_offices.py`

خلاص — المسارات والواجهة يخدمو بلا تبديل.
