    f 1) ربط فيسبوك (الصفحة)
    1. دخل لـ developers.facebook.com بحساب الفيسبوك اللي هو أدمين على صفحة Budac ← My Apps ← Create App. اختار الـ use case: Manage everything on your Page.
    2. من Tools ← Graph API Explorer: اختار تطبيقك، ثم Get User Access Token وعلّم الصلاحيات: pages_show_list · pages_read_engagement · pages_manage_posts. اضغط Generate Access Token ووافق على الصفحة.
    3. مدّد التوكن لـ«طويل المدى»: من Access Token Debugger اضغط Extend Access Token، ولا ادعي /oauth/access_token?grant_type=fb_exchange_token&client_id=APP_ID&client_secret=APP_SECRET&fb_exchange_token=التوكن.
    4. في Explorer، بالتوكن الطويل، اطلب GET me/accounts. تلقى قائمة صفحاتك: id تاع Budac = FB_PAGE_ID، وaccess_token = FB_PAGE_TOKEN (توكن الصفحة اللي يجي من توكن طويل ما ينتهيش).
    5. في Railway ← Variables زيد FB_PAGE_ID وFB_PAGE_TOKEN. استنى الـ deploy يكمل ورجع هنا واضغط فحص الاتصال.
    ◎ 2) ربط انستغرام
    1. حساب انستغرام لازم يكون Business ولا Creator (من إعدادات انستغرام ← نوع الحساب)، ومربوط بصفحة الفيسبوك (إعدادات الصفحة ← الحسابات المرتبطة).
    2. في Graph API Explorer زيد صلاحيتين: instagram_basic وinstagram_content_publish، وعاود خطوات 2-4 تاع فيسبوك باش التوكن الجديد يحملهم.
    3. بعد ما تحط FB_PAGE_ID وFB_PAGE_TOKEN الجداد، اضغط هنا فوق «جيب IG_USER_ID تاعي» — ياخذو لك الرقم وحدو. حطو في Railway باسم IG_USER_ID.
    4. نفس FB_PAGE_TOKEN يخدم لانستغرام. بعد الـ deploy اضغط فحص الاتصال.
